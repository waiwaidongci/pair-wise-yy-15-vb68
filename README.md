# hxyfront-62014 赛鸽训放 · 电子环发放与成绩复核台

面向赛鸽棚的训放记录工具，在原有训放记录基础上扩展出**电子环发放**与**成绩复核**闭环。

## 核心规则

1. **一羽一环**：每羽赛鸽同一时间只认一枚在役电子环；已有在役环时拒绝再发。重复点击或并发发环共用首次发环流程，全部沿用首次结果（幂等），绝不产生第二枚在役环。
2. **成绩双重绑定**：训放成绩必须同时绑定放飞当刻的**在役电子环**和放飞前**最近一次校准**，速度 = 放飞距离 ÷（归巢时间 − 放飞时间）。
3. **七十二小时有效期**：放飞时距最近校准超过 72 小时，或没有校准记录，成绩只进**待复核**——不计排行，也不计入未归巢。
4. **停用即失效**：电子环停用后关联成绩立即失效并重算——无新环接替进待复核；有新环接替按**换环**处理，旧成绩永久**留档**，不回排行。
5. **更正即重算**：更正发放记录或校准记录，关联成绩立即失效并按新台账重算，每次状态变化都在成绩的「重算轨迹」中留痕。
6. **分层承载、刷新一致**：规则（纯函数）、台账（只追加事件）、页面（派生视图）分离；所有视图由事件流 fold 派生，持久化在 localStorage，刷新或跨标签页后环档案、复核队列与成绩完全一致。

## 分层结构

```
src/
├── rules/            # 规则层：纯 TypeScript，不依赖 React / 存储
│   ├── types.ts      # 领域模型与只追加事件
│   ├── engine.ts     # 发环校验、72h 校准、成绩评定、排行选择器
│   └── fold.ts       # 事件溯源：事件流 -> 物化状态（含重算轨迹）
├── ledger/           # 台账层：持久化与种子数据
│   ├── storage.ts    # localStorage 载入/保存/重置
│   └── seed.ts       # 演示台账（覆盖各类待复核与换环留档）
├── hooks/
│   └── useLedger.ts  # 应用 API：发环/停用/换环/校准/更正/登记成绩
├── components/       # 页面层：全部为台账派生视图
│   ├── Overview.tsx       # 鸽棚总览、排行、未归巢、单羽档案（按血统筛选）
│   ├── IssueDesk.tsx      # 发环台：发环（含并发幂等演示）、停用/换环、更正发放
│   ├── CalibrationDesk.tsx# 校准台：登记/更正校准、72h 新鲜度
│   ├── TrainingDesk.tsx   # 训放场次与成绩登记、当场排行与未归巢
│   ├── ReviewQueue.tsx    # 复核台：待复核队列、留档成绩、场次更正
│   └── RulesLedger.tsx    # 规则说明 + 只追加事件台账
scripts/check-rules.ts    # 规则断言脚本（仓库根 scripts/）
```

## 页面

- **鸽棚总览**：有效归巢率、平均速度、有效未归巢、在役环/待复核数；按血统筛选；单羽档案含电子环履历、校准履历、历史成绩。
- **发环台**：发环、模拟并发双发（验证幂等）、停用/换环、电子环台账、更正发放。
- **校准台**：在役环校准状态（新鲜/超 72h/未校准）、登记校准、更正最近校准。
- **训放成绩**：建立场次、登记归巢/未归巢（自动绑定当刻在役环）、当场排行、场次更正。
- **复核台**：待复核队列（原因 + 重算轨迹 + 一键去校准）、换环留档成绩。
- **规则与台账**：规则卡片与全量只追加事件日志，支持重置演示数据。

```bash
npx esbuild scripts/check-rules.ts --bundle --platform=node --format=esm \
  --outfile=/tmp/check-rules.mjs && node /tmp/check-rules.mjs
```

覆盖：一羽一环、发环幂等、环停用待复核、校准缺失/超 72h、换环留档不复活、
更正发放/校准立即重算、排行与未归巢口径、事件重放与增量 fold 一致性（33 项断言）。
