# hxyfront-62014 赛鸽电子环发放与成绩复核台

面向赛鸽棚的训放管理工具：电子环发放、读写器校准、训放成绩绑定、排行与待复核队列。

## 业务规则

1. **一羽一环在役**：每羽赛鸽同一时间只认一枚在役电子环。重复或并发发环沿用首次结果（同一鸽在途请求合并），电子环号全局唯一。
2. **成绩绑定环与最近校准**：训放成绩绑定开笼时点的在役环和开笼前最近一次校准。
   - 环停用 / 在役环缺失 / 发环晚于开笼：只进**待复核**；
   - 校准缺失或距开笼 **超过 72 小时**：只进**待复核**；
   - 待复核成绩**不计排行，也不计未归巢**。
3. **更正即失效重算**：更正发放记录或校准记录后，关联成绩立即失效并重新判定，失效留痕挂在成绩上。
4. **换环旧成绩留档**：换环后旧环退役，旧成绩永久留档（`archived`），不参与排行与未归巢；新批次成绩绑定新环。
5. **规则 / 台账 / 页面分离**：
   - `src/domain/`：纯函数规则层（事件折叠、成绩判定、发环裁决），不依赖 React/DOM；
   - `src/ledger/`：台账层，事件只追加并持久化到 `localStorage`，命令 API 带每羽发环互斥；
   - `src/ui/`：页面层，通过 `useSyncExternalStore` 只读派生视图。
   刷新后从事件流重新折叠，环档案、复核队列与成绩保持一致。

## 页面

- **电子环发放台**：赛鸽档案、发环（含“模拟并发发环”按钮验证去重）、换环、停用、校准、发放/校准记录更正。
- **训放成绩台**：建批选鸽开笼、登记归巢（自动算均速）、当批排行、未归巢提醒、换环留档查看。
- **成绩复核台**：待复核队列（按原因归集，可人工确认出队，仍不计排行）、按血统筛选的单羽档案与历史成绩。
- **规则与台账**：规则说明、事件流水（可按类型过滤）、重置演示数据。

首次打开会生成锚定当前时间的演示台账：包含有效、校准过期、校准缺失、环停用、换环留档、有效未归巢等场景。

## 技术栈

React 19 + Vite + TypeScript（无额外运行时依赖）。持久化使用 `localStorage`。

## 本地运行

```bash
npm install
npm run dev        # http://localhost:62014
npm test           # 规则层 + 台账层冒烟测试（29 + 17 条断言）
npm run typecheck
npm run build
```

开发端口：62014
